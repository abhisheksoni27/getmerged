# Design System: Neo-Brutalism

All UI components and pages in opendoor must strictly adhere to the Neo-Brutalist design style.

## Core Rules

1. **Bottom-Line Borders (Mandatory - Never Skip)**
   - Components, cards, headers, buttons, navigation items, and section dividers must feature prominent, visible bottom-line borders (e.g. `border-b-2`, `border-b-4`, or hard borders like `border-b-black`).
   - Do not omit bottom-line borders on interactive or structural UI elements.

2. **High-Contrast & Raw Geometry**
   - Use high-contrast solid colors, distinct black outlines, and sharp edges (`rounded-none` or minimal `rounded-sm`).
   - Hard drop shadows with zero blur (e.g. `shadow-[4px_4px_0px_0px_#000]`).

3. **Typography & Layout**
   - Bold, stark typography with clear visual hierarchy.
   - Clean, unambiguous visual separation between structural containers.
