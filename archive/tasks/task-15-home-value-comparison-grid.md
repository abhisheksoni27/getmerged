# Jira Story: "Why Opendoor" Comparison Value Matrix

## Epic Link
EPIC-201: Homepage Revamp & User Retention

## Description
As a developer deciding whether to use opendoor, I want to see a clear side-by-side comparison of manual open-source hunting vs. opendoor intelligence to understand its value.

## Why
Users need logical reasons to stick to a platform. A bold comparison grid clearly demonstrates the pain points of the status quo (wasted hours, ghost towns, ignored PRs) vs. our solution (guaranteed reviews, active maintainers, high merge rates).

## Specific Key Result
- **User Stickiness**: Increase Day 7 return visits by 25%.
- **Scroll Depth**: Increase homepage scroll depth (at least 60% of page viewed) to 80% of all sessions.

## How to Solve (Solution)
1. **Neobrutalist Matrix Table**: Design a side-by-side comparison grid on the homepage using contrasting columns:
   - **Column 1 (The Old Way)**: Ignored PRs, silent maintainers, toxic review vibes, manual search struggles.
   - **Column 2 (The Opendoor Way)**: Mathematical merge telemetry, verified first-timer checkmarks, active maintainers, automated notifications.
2. **Visual Accents**: Use playful cross icons (red) for Column 1 and neobrutalist check stickers (cream/dark) for Column 2.
3. **Persuasive Call-to-Action**: End the section with a prominent "Open Your First Door" CTA button leading to the matcher wizard.
