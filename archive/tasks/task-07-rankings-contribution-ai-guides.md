# Jira Story: Integrate Language-Specific AI Contribution Guidelines Quick-Tips

## Epic Link
EPIC-103: Dynamic Language Rankings Revamp

## Description
As a first-time contributor landing on rankings pages, I want to view dynamic, language-specific quick-tips for onboarding (e.g. how to set up Rust toolchains or Go workspace paths) to jumpstart my contribution.

## Why
Providing direct, high-value technical advice within rankings page headers signals deep topical authority. This keyword-rich, original programmatic text satisfies Google's "Helpful Content Update" requirements.

## Specific Key Result
- **Organic Impressions**: Increase search impressions for dynamic language ranking pages by 80%.
- **Click-Outs**: Drive 20% click-out rate to external contribution guideline documents.

## How to Solve (Solution)
1. ** Programmatic Tips Block**: Create a curated, dynamic quick-tips component at the top of `/rankings/[lang]` pages based on the ecosystem.
2. **Community Standards Integration**: Highlight common requirements (e.g., standard pre-commit hooks, formatting conventions like `cargo fmt` or `go fmt`).
3. **Responsive Cards**: Render this block as a neobrutalist warning/info sticker container with clean typography and brand-cream background highlight colors.
