# Jira Story: Gamified Contributor Milestones & Achievement Board

## Epic Link
EPIC-201: Homepage Revamp & User Retention

## Description
As a regular contributor, I want to track my active contribution milestones (e.g. number of PRs submitted to S-tier repos, triage assist counts) to build my personal contribution profile.

## Why
Retention is heavily driven by gamification and profile value. Giving users achievement badges (e.g., "First S-Tier PR Merged", "Maintainer Delight Leader", "Ecosystem Guru") provides a strong incentive to return and keep their profile updated.

## Specific Key Result
- **Day 30 Retention**: Boost long-term user retention (D30) to 30%.
- **Profile Completion**: Drive a 45% completion rate of contributor profiles.

## How to Solve (Solution)
1. **Achievement Dashboard Tab**: Add a "My Achievements" tab to the homepage dashboard for authenticated users.
2. **Gamified Badge Stickers**: Design bold neobrutalist achievement stickers (e.g. "PR Sniper", "Vibe Validator", "Open Door Explorer") that unlock as users submit PRs through opendoor.
3. **LinkedIn Integration**: Provide a single-click button to export these achievements directly to their LinkedIn profile certifications.
