# Jira Story: Interactive C-Rank Calculator Widget for Maintainers

## Epic Link
EPIC-201: Homepage Revamp & User Retention

## Description
As a repository maintainer or contributor, I want to input my project's PR merge rates and response speeds to calculate and preview our potential C-Rank tier.

## Why
Interactivity is key to engaging both contributors and maintainers. A calculator widget acts as a gamified hook. Maintainers will test their repos, get excited about their S/A tier potential, and claim their badges, naturally creating inbound organic loops.

## Specific Key Result
- **Widget Interactions**: Achieve a 10% conversion rate of visitors interacting with the calculator.
- **Maintainer Claims**: Convert 5% of calculator visits to official repository indexing requests.

## How to Solve (Solution)
1. **Interactive Slider Form**: Build a widget card on the homepage containing sliders for:
   - **Average Response Hours** (1h to 72h+)
   - **PR Acceptance Rate** (0% to 100%)
   - **First-Timer Success Rate** (0% to 100%)
2. **Real-time Badge Preview**: Dynamically update a neobrutalist badge display (e.g. S, A, B, C, D) as the sliders move.
3. **Submit Repo CTA**: Display a "Claim this badge & get indexed" action button linking to a simple repository submission form.
