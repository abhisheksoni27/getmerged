2. Audit Categories

2.1 Technical SEO

Score: 86/100

What Works

  • SSR-First Next.js architecture with instant pre-rendered HTML
  • Comprehensive robots.txt explicitly allowing AI search crawlers (GPTBot, ClaudeBot, PerplexityBot)
  • Strict HSTS header with preload enabled
  • Clean self-referencing canonical tags across all templates
  • Cloudflare CDN edge caching with stale-while-revalidate

Findings

Sitemap File URL Cap Exceeded Critical

https://getmerged.abhishekco.de/sitemap/main.xml contains 66,349 URLs, exceeding Google Search Console's hard limit of 50,000 URLs per sitemap file.

Recommendation: Chunk main.xml into paginated sitemaps of <= 45,000 URLs each (e.g. main-1.xml, main-2.xml) in the sitemap index.

High-Value Transactional Pages Missing from Sitemaps High

/pricing, /talent, and /maintainers are omitted from the sitemap index.

Recommendation: Add high-priority static marketing and pricing routes to a dedicated static.xml sitemap.

Conflicting Security Headers Emitted Medium

Server returns conflicting x-frame-options headers ('DENY' and 'SAMEORIGIN') and duplicate referrer-policy headers.

Recommendation: Deduplicate security headers in next.config.js and Cloudflare edge rules.

Cache-Control: no-store on Public HTML Medium

Public pre-rendered pages return 'Cache-Control: ... no-store', preventing browsers from utilizing bfcache for instant back/forward navigation.

Recommendation: Remove no-store from public SSR routes; retain only s-maxage and stale-while-revalidate.

Non-Redirecting Trailing Slashes Low

Both trailing slash and non-trailing slash URLs return HTTP 200 without a 301 redirect.

Recommendation: Set trailingSlash: false in next.config.js to enforce 301 redirects to canonical URLs.

  • High information density across 167k+ repository pages

Findings

Default /compare and /pricing routes have under 40 words in initial SSR HTML when unselected.

Recommendation: Pre-render curated comparison showdowns and comprehensive feature comparison matrices on SSR.

Marketing Cliché Usage Low

Content quality scorer identified 'elevate your' phrasing in component previews.

Recommendation: Replace with punchy developer-centric verbs ('accelerate', 'merge faster', 'inspect telemetry').

2.3 On-Page SEO & Structure

Score: 85/100

What Works

  • Keyword-rich, unique meta titles and descriptions across all ecosystem rankings and scorecards
  • OpenGraph and Twitter summary cards with dynamic scorecard image URLs
  • Strong semantic landmark markup (14 landmarks, 115 semantic links)

Findings

Multiple H1 Elements on Homepage High

Homepage renders two distinct <h1> tags, creating semantic hierarchy ambiguity.

Recommendation: Consolidate into a single primary <h1> tag for the homepage hero.

Missing H1 on Pricing and Compare Routes High

/pricing and /compare lack an <h1> element in their SSR markup.

Recommendation: Promote section headings to <h1> tags on both routes.

Text Concatenation Spacing Glitches in Headings Medium

Dynamic headings concatenate words without spaces (e.g. 'Open-SourceRustRepositories', 'forrust-lang/rust', 'dani84bs/AnnotationSync.kopluginvsntop/ntopng').

Recommendation: Add explicit spaces in JSX interpolation strings.

2.4 Schema / Structured Data

Score: 94/100

What Works

  • Dataset schema on rankings with downloadable JSON distribution links
  • ItemList schema on rankings enumerating top 50 repos
  • SoftwareSourceCode and BreadcrumbList schemas on all repository scorecards
  • WebSite and WebApplication schemas on homepage with SearchAction query input
  • Product schema with tiered Offer definitions on /pricing

Findings

FAQPage Schema Legacy Usage Info

FAQPage schema is used on repository and ranking pages. Google retired FAQ rich results in May 2026.

Recommendation: Keep markup for general semantic understanding, but focus rich result efforts on Dataset, ItemList, and SoftwareApplication.

Product Schema Missing Optional Attributes Low

Product schema on /pricing lacks 'image' or 'brand' schema properties.

Recommendation: Add brand and logo references to the Product JSON-LD schema.

2.5 Performance (CWV)

Score: 88/100

What Works

  • Edge-cached SSR HTML with ~25ms TTFB via Cloudflare

  • Zero CLS layout stability on static scorecard grids

Findings

Render-Blocking Third-Party CDN Stylesheet High

cdn.jsdelivr.net devicon.min.css is loaded synchronously in <head>, blocking initial render.

Recommendation: Self-host the devicon CSS or load asynchronously / inline required SVGs.

Speculation Rules API Missing Low

Recommendation: Add Speculation Rules script for instant subpage transitions.
